Cómo publicar una nueva versión
  1. Abre app/version.py
  2. Actualiza VERSION, BUILD_DATE y RELEASE_NAME
  3. Añade una nueva entrada al principio de la lista CHANGELOG con los cambios de esta release
  4. Reinicia el servidor — la nueva versión aparece automáticamente en el footer y en esta página
# app/version.py
VERSION = "3.2.0"
BUILD_DATE = "2026-07-01"
RELEASE_NAME = "Nombre de la release"
